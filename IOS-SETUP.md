# Проверка iPhone-демо

Нужны полный Xcode и компонент iOS Simulator. На текущем Mac macOS 26.5.2 совместим с Xcode 26.6. Загрузите эту версию у Apple: https://developer.apple.com/download/all/?q=Xcode%2026.6 . Если требуется вход Apple ID или принятие лицензии, выполните их самостоятельно.

1. Распакуйте Xcode и поместите `Xcode.app` в `/Applications` («Программы»).
2. Откройте Xcode, завершите первоначальную настройку и установите компонент iOS Simulator в Settings → Components / Platforms (название зависит от версии).
3. Откройте Simulator из Xcode → Open Developer Tool → Simulator и запустите один iPhone.
4. Изменять глобальный `xcode-select` не обязательно: скрипт использует установленный Xcode через `DEVELOPER_DIR`.

Далее из папки проекта:

```sh
./build-ios-demo.sh
./run-ios-demo.sh
```

Если запущено несколько симуляторов, укажите конкретный UDID: `./run-ios-demo.sh <UDID>`. Скрипт устанавливает только отдельное наше приложение `local.again.channelrecovery.iosreference`; установленные приложения Telegram и их аккаунты не меняются. Локальный сервер остаётся в терминале до Ctrl+C. На физическом iPhone этот способ подключения к loopback-серверу не рассчитан.

Состояние проверки на 19 ноября 2026: Xcode 26.6 установлен, `./build-ios-demo.sh` успешно собрал приложение с iOS 26.5 SDK и `-warnings-as-errors`. Среда iOS Simulator 26.5 установлена. На iPhone 17 проверены удаление и восстановление старого текста, сохранение удаления после перезапуска сервера/приложения, восстановление фото, а также восстановление и воспроизведение видеокружка. Путь интерфейса проверен по пути профиль → Изменить → Недавние действия → удержание → Восстановить.

Это самостоятельное iPhone-демо общего модуля, а не полная сборка Telegram-iOS. Полный клиент зафиксированной версии требует указанного в его `versions.json` Xcode 27.1; проверка этого клиентского патча является отдельным шагом. Работа самостоятельного интерфейса проверена в симуляторе отдельно; это не подтверждает сборку или исполнение полного клиентского патча.
