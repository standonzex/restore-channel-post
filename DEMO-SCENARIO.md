# zexeAI — сценарий iPhone 1.8

Свежая iPhone-база запускается пустой. Существующие демонстрационные данные сохраняются: для нового показа открыть info внизу → «Начать с пустого канала». Это очищает только собственную синтетическую базу.

1. Ввести первый пост ниже и отправить стрелкой. Поддержка лёгкой Markdown-разметки в этом хосте показывает слова жирным; это формат примера, не новое предложение изменения редактора Telegram.
2. Удерживать значок камеры справа от поля около 4 секунд. Появятся круглый анимированный предпросмотр и таймер; отпустить для отправки. Сдвиг влево отменяет запись, короткое касание ничего не отправляет. Это имитация камеры в Simulator на подготовленном клипе согласованного вымышленного персонажа: реальная камера не запрашивается и не записывается.
3. Воспроизвести кружок, удержать его край → «Удалить» → «Удалить у всех».
4. Название канала → «Изм.» → прокрутить → «Недавние действия».
5. Удержать удалённый кружок → «Восстановить». Он вернётся после текста, с теми же ID, датой, временем и медиа; после восстановления его можно воспроизвести.

```text
всем สวัสดี! 😎
тут я буду рассказывать про свою **life**, обсуждать **chisme**, делиться **foto** и **vidéos**, и иногда писать про **moda**!!!
```

Новые публикации получают настоящее время локального сервера. Дата в восстановлении не задаётся клиентом. Для проверки возвращения очень старого поста в info выбрать «Загрузить примеры старых постов»: там остаётся пример 3 апреля 2022 / 17:30.

Аватар — отдельный оригинальный векторный серебристый полумесяц на чёрном. Персонаж для фото и кружка вымышленный; исходные фотографии реальных людей в код не включены. Кружок создан из полученной анимации: 16 исходных кадров / 1,92 с, два повтора дают 3,84 с. Сами кадры лица при преобразовании в MOV не менялись.

В Simulator смешанный тайский/русский текст и emoji надёжно вставляются из постоянного буфера обмена: открыть этот файл в локальном редакторе, скопировать текст и вставить в Simulator. Временная подмена буфера инструментом автоматизации может не успеть синхронизироваться с iOS.

Для записи под более широкий экран корпуса: `./run-ios-demo.sh <simulator-udid> --capture-canvas`. Этот режим использует те же компоненты и локальные операции, компонуя интерфейс в 402 × 612 pt. Меню сокращено по высоте строк, без удаления команд. После записи вырезается весь прямоугольник 1206 × 1836 px, без изменения пропорций. На iPhone 17 из текущего дубля: x=0, y=393; на другом устройстве границы нужно измерить заново. Видеорежим прячет служебную полосу; о локальном прототипе сообщают сопровождающие документы.
